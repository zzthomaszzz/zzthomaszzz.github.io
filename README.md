# zzthomaszzz.github.io

Personal portfolio site. Single page, vanilla HTML/CSS/JS with Three.js and cannon-es from pinned CDN versions.
Drive the car, knock the letters over, press Enter at a sign to open a project.

- `./?list` shows the plain page (also used automatically for reduced motion or no WebGL).
- `./?drive` forces the 3D scene even with reduced motion on.

Run locally with any static server, e.g. `python -m http.server 8080`, then open http://localhost:8080.

Deploys from the `main` branch root via GitHub Pages.
